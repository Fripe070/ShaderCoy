# ShaderCoy

A powerful shader-editor for the web.

Features:

- Real-time GLSL shader compilation and preview, both for vertex and fragment shaders.
- A full 3D viewport.
  - Lots of default primitives to pick from.
  - Ability to upload custom models, which are loaded using a custom [WebAssembly port of Assimp](https://github.com/Fripe070/assimpts).
  - Dynamic and fixed sizing modes.
  - 2D, perspective and orthographic projection modes with aplicable camera controls.
- Support for uploading custom textures, up to the GPUs limit.
- Lots of themes to fit all tastes.
